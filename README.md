# App_limpeza
# Cleaning Schedule Web App

A responsive web application for managing cleaning service appointments, developed as a real-world learning project for web development. 

## Features 
- Calendar-based schedule view
- Client registration
- Employee registration
- Personalized cleaning notes 
- Service duration control
-  Daily appointment overview

 ## Technologies
-   HTML5
-  CSS3
-  JavaScript
-  Git & GitHub
-  Firebase (planned)
